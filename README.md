## 🛰️ Mission Briefing

```yaml
callsign:   Suchet Kumbar
base:       VIT Chennai · B.Tech, 3rd year · Chennai, India 🇮🇳
trajectory: AI + Robotics ──▶ Cloud ──▶ Agentic systems
payload:    [ machine-learning, robotics, full-stack, iot, ai-agents ]
fuel:       projects with real stakes
```

I build at the intersection of **robotics, machine learning, and full-stack development** — and I like projects with real stakes: hardware that could fail, models that need to generalize, interfaces that someone other than me actually has to use.

<br/>

## 🧭 How I Navigate

| | Principle | In practice |
|:-:|---|---|
| 🚀 | **Launch early** | A working prototype beats a perfect plan. I ship v0, then iterate in orbit. |
| 🔭 | **Learn in public** | Repos like `100DaysOfML`, `AgenticAI` and `websockets` are my flight logs — step by step, from first principles. |
| 🛠️ | **Hardware meets software** | Cameras, servos and sensors keep models honest. If it can't survive the real world, it isn't done. |
| 🧠 | **AI as a teammate** | LLMs, agents and MCP tools wired into products — not demos, but things people use. |
| ☁️ | **Built to scale** | Typed end to end, deployed on the cloud, designed so the next person can fly it. |
